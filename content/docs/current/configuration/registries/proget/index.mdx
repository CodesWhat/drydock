The `proget` registry lets you configure a self-hosted [Inedo ProGet](https://inedo.com/proget) container registry integration.

ProGet is self-hosted, so `URL` is required and drydock only matches images whose registry host is exactly the configured host.

## Variables

| Env var | Required | Description | Supported values | Default value when missing |
| --- | :---: | --- | --- | --- |
| `DD_REGISTRY_PROGET_{REGISTRY_NAME}_URL` | 🔴 | Registry URL (e.g. `https://proget.acme.com`) |  | |
| `DD_REGISTRY_PROGET_{REGISTRY_NAME}_LOGIN` | ⚪ | ProGet username | `DD_REGISTRY_PROGET_{REGISTRY_NAME}_PASSWORD` must be defined | |
| `DD_REGISTRY_PROGET_{REGISTRY_NAME}_PASSWORD` | ⚪ | ProGet password or API key | `DD_REGISTRY_PROGET_{REGISTRY_NAME}_LOGIN` must be defined | |
| `DD_REGISTRY_PROGET_{REGISTRY_NAME}_AUTH` | ⚪ | Base64-encoded `login:password` string | `DD_REGISTRY_PROGET_{REGISTRY_NAME}_LOGIN/PASSWORD` must not be defined | |
| `DD_REGISTRY_PROGET_{REGISTRY_NAME}_CAFILE` | ⚪ | Path to custom CA certificate file |  | |
| `DD_REGISTRY_PROGET_{REGISTRY_NAME}_INSECURE` | ⚪ | Disable HTTPS certificate validation (plain HTTP is selected by the registry `URL` scheme) | `true`, `false` | `false` |
| `DD_REGISTRY_PROGET_{REGISTRY_NAME}_CLIENTCERT` | ⚪ | Path to client certificate file for mTLS | `DD_REGISTRY_PROGET_{REGISTRY_NAME}_CLIENTKEY` must also be defined | |
| `DD_REGISTRY_PROGET_{REGISTRY_NAME}_CLIENTKEY` | ⚪ | Path to client key file for mTLS | `DD_REGISTRY_PROGET_{REGISTRY_NAME}_CLIENTCERT` must also be defined | |

## Examples

### Configure for anonymous access

<Tabs items={["Docker Compose", "Docker"]}>
<Tab value="Docker Compose">

```yaml
services:
  drydock:
    image: codeswhat/drydock:1.9.0-rc.1
    ...
    environment:
      - DD_REGISTRY_PROGET_PRIVATE_URL=https://proget.acme.com
```

</Tab>
<Tab value="Docker">
```bash
docker run \
  -e "DD_REGISTRY_PROGET_PRIVATE_URL=https://proget.acme.com" \
  ...
  codeswhat/drydock:1.9.0-rc.1
```
</Tab>
</Tabs>

### Configure with login and password

<Tabs items={["Docker Compose", "Docker"]}>
<Tab value="Docker Compose">

```yaml
services:
  drydock:
    image: codeswhat/drydock:1.9.0-rc.1
    ...
    environment:
      - DD_REGISTRY_PROGET_PRIVATE_URL=https://proget.acme.com
      - DD_REGISTRY_PROGET_PRIVATE_LOGIN=myuser
      - DD_REGISTRY_PROGET_PRIVATE_PASSWORD=xxxxx
```

</Tab>
<Tab value="Docker">
```bash
docker run \
  -e "DD_REGISTRY_PROGET_PRIVATE_URL=https://proget.acme.com" \
  -e "DD_REGISTRY_PROGET_PRIVATE_LOGIN=myuser" \
  -e "DD_REGISTRY_PROGET_PRIVATE_PASSWORD=xxxxx" \
  ...
  codeswhat/drydock:1.9.0-rc.1
```
</Tab>
</Tabs>

### Configure with base64 auth

<Tabs items={["Docker Compose", "Docker"]}>
<Tab value="Docker Compose">

```yaml
services:
  drydock:
    image: codeswhat/drydock:1.9.0-rc.1
    ...
    environment:
      - DD_REGISTRY_PROGET_PRIVATE_URL=https://proget.acme.com
      - DD_REGISTRY_PROGET_PRIVATE_AUTH=YOUR_BASE64_AUTH
```

</Tab>
<Tab value="Docker">
```bash
docker run \
  -e "DD_REGISTRY_PROGET_PRIVATE_URL=https://proget.acme.com" \
  -e "DD_REGISTRY_PROGET_PRIVATE_AUTH=YOUR_BASE64_AUTH" \
  ...
  codeswhat/drydock:1.9.0-rc.1
```
</Tab>
</Tabs>
